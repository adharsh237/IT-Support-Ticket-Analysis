# IT Support Ticket Analysis

## Overview
This project uses PostgreSQL to analyze IT support tickets, including resolution times, ticket status, and technician workload.

## Tools
- PostgreSQL
- pgAdmin 4
- SQL

## Database Schema
Table: support_tickets
- ticket_id (PK)
- employee_name
- department
- issue_type
- priority_level
- ticket_status
- assigned_to
- resolution_time_hours
- created_date

## Sample Queries
- View open tickets
- Count tickets by department
- Average resolution time
- Tickets assigned to each technician

## Insights
- High priority tickets take the longest to resolve
- Certain departments generate more tickets than others
